# 화면 설계

CLAUDE.md의 목표와 규칙을 화면, 데이터, 코드 구조로 옮긴 문서입니다.
화면 시안으로 동작을 확정했고(2026-11-17), 소스는 이 문서를 기준으로 합니다. 바꿀 때는 이 문서를 먼저 고칩니다.
화면 그림이 들어간 화면정의서와 매뉴얼(파워포인트)은 저장소 밖 산출물 폴더에 있습니다.

---

## 1. 전체 구조

- 화면 4개: **오늘 / 이번 주 / 설정 / 백업**. 아래쪽 탭 막대로 이동 (한 손 조작)
- 주의 시작은 **월요일**, 시간은 **24시간제**
- 입력할 때마다 바로 저장 (저장 버튼 없음)
- 확인·입력 창은 브라우저 기본 창 대신 아래에서 올라오는 창으로 만든다 (홈 화면 앱에서 기본 창이 막히는 경우가 있음)

### 항목의 입력 방식 3가지

| 입력 방식 | 오늘 화면 | 설정에서 정하는 것 | 합계 |
|---|---|---|---|
| 체크 | O / △ / X | 요일·시간 줄 여러 개 (요일, 시작 시간, 몇 분, 내용). 한 요일은 한 줄에만 | 들어감 (O, △ 달성) |
| 시간 입력 | 누르면 지금 시간, 직접 입력도 가능 | 요일, 목표 시간, 목표 이전/이후 달성, 밤 시간 해석 | 목표가 있으면 들어감 |
| 켜기/끄기 | 스위치 | 요일, 합계 방식 (켜면 달성 / 끄면 달성 / 안 넣음) | 안 넣음이면 횟수만 |

- 기록이 생긴 항목은 입력 방식을 바꿀 수 없다 (새 항목을 만든다)
- 삭제하면 숨김(`archived`) 처리(논리 삭제). 지난 기록은 남고, 설정의 '삭제한 항목'에서 되살릴 수 있다
- 삭제한 항목은 그 항목이 할 일이었던 날(끝난 날은 필드가 있는 날, 오늘은 값을 입력한 날)에만 이름 옆 '(삭제)'와 함께 보인다. 삭제 뒤 날짜에는 나오지 않는다

## 2. 화면별 설계

### 2-1. 오늘

```
┌──────────────────────────────────────┐
│ ◀   오늘 · 11월 17일 (화)          ▶ │
│ ⚠ 어제와 그제 모두 0이에요. △ 하나라도! │  ← 이틀 연속 0일 때만
├──────────────────────────────────────┤
│ 오늘 합계                        3 / 7 │
├──────────────────────────────────────┤
│ 기상          목표 07:30 이전  [07:20 ✓] │  ← 시간 입력
│ 07:10 (10분) 스트레칭          [O][△][X] │  ← 체크
│ 19:00 (30분) 운동                        │
│   홈트 · 19:00~19:30           [O][△][X] │
│ 취침          목표 23:30 이전 [눌러서 입력] │
│ 야식 (먹은 날)  끄면 달성          (스위치) │  ← 켜기/끄기
│ 오늘 없는 항목 1개 보기                   │
├──────────────────────────────────────┤
│ 비고  [                              ]  │
└──────────────────────────────────────┘
```

- 모든 항목(체크 · 시간 입력 · 켜기/끄기)을 설정 순서 그대로 한 목록에 보여 준다. 따로 나누지 않는다
- 그날 요일에 해당하는 항목만 나오고, 나머지는 "오늘 없는 항목"으로 접어 둔다
- O/△/X: 누르면 선택, 같은 버튼을 다시 누르면 해제. 버튼 44px 이상
- 시간 버튼: 빈칸을 누르면 지금 시간이 바로 들어간다 (오늘 날짜이고 밤 해석이 꺼진 항목)
  - 값이 있거나, 밤 해석 항목(취침)이거나, 지난 날짜면 입력 창이 열린다: 지금 시간 넣기 / 직접 입력 / 지우기
- 날짜 ◀ ▶ 로 지난 날짜를 보고 고칠 수 있다 (미래로는 못 감)
- '끄면 달성' 스위치를 켜면 빨강, 그 밖에는 초록

### 2-2. 이번 주

```
┌─────────────────────────────────────────────┐
│ ◀  11/16 ~ 11/22  ▶               이어간 주 3주째 │
├──────┬──┬──┬──┬──┬──┬──┬──┬─────┤
│      │월│화│수│목│금│토│일│ 합계 │
│ 기상  │07:10│08:05│…          │ 3/7 │  ← 시각 표시, 달성 초록 / 미달성 빨강
│ 운동  │O │△ │- │O │X │- │- │ 3/4 │
│ 취침  │22:50│…               │ 5/7 │
│ 야식  │  │  │✓ │✓ │  │…     │ 5/7 │  ← 켜기/끄기: 합계 방식대로 색
│ 하루  │5 │4 │0 │0 │6 │…     │     │  ← 맨 아래. 0은 주황 바탕
└──────┴──┴──┴──┴──┴──┴──┴──┴─────┘
```

- 행 순서는 설정 순서 그대로, 하루 합계 행은 맨 아래
- 빈칸 = 미입력, `-` = 그날 할 일이 아님
- 항목별 합계는 달성 / 해야 할 날. 합계에 안 넣는 켜기/끄기 항목은 "n회"
- 칸을 누르면 그날의 오늘 화면으로 이동
- 삭제한 항목은 그 주에 할 일이었던 날이 있을 때만 줄이 생기고, 이름 아래 '(삭제)' 표시

### 2-3. 설정

```
┌──────────────────────────────────────┐
│ 항목 · 오늘 화면과 이번 주 표에 이 순서대로 │
│ [시간 입력] 기상             ↑ ↓ ✎ 🗑 │
│   매일 · 목표 07:30 이전 · 편집 ▼        │
│ [체크] 운동                  ↑ ↓ ✎ 🗑 │
│   월·수·금 19:00 30분 걷기 / 화·목 … · 편집 ▼ │
│ [켜기/끄기] 야식 (먹은 날)    ↑ ↓ ✎ 🗑 │
│   매일 · 끄면 달성 · 편집 ▼              │
│ + 항목 추가                             │
└──────────────────────────────────────┘
```

- 편집 ▼을 누르면 입력 방식별 편집이 펼쳐진다
  - 공통: 입력 방식 선택 (기록이 있으면 잠김)
  - 체크: 요일 칩 · 시작 시간 · 몇 분 · 내용, + 요일·시간 줄 추가. 다른 줄에 있는 요일을 누르면 이 줄로 옮겨진다
  - 시간 입력: 요일 칩 · 목표 시간 · 이전/이후 · 밤 시간 해석 스위치
  - 켜기/끄기: 요일 칩 · 합계 방식
- 항목 추가: 이름 입력 + 입력 방식 선택. 목록 맨 끝에 추가. 새 기본값은 체크 = 월~금 30분, 시간 입력 = 매일·목표 없음, 켜기/끄기 = 매일·합계 안 넣음
  - 삭제한 항목과 이름이 같으면 "예전 항목 되살리기 / 새 항목으로 만들기"를 묻는다
- 삭제한 항목: 목록 아래 "삭제한 항목 N개 보기 ▼"(삭제한 것이 없으면 안 보임). 펼치면 흐리게 보이고 [되살리기]만 있다
  - 되살리기: 삭제 표시만 지움 → 같은 id라 지난 기록과 이어지고, 설정도 예전대로, 원래 자리로 돌아감
  - 완전 삭제는 두지 않는다 (지난 합계가 틀어지지 않게)

### 2-4. 백업

```
┌──────────────────────────────────────┐
│ 마지막 내보내기   11월 1일 (일)  16일 전 │
│ ⚠ 2주 넘게 백업하지 않았어요            │
│ 보내기: [공유하기 (카톡 등)]             │
│        [텍스트로 복사] [파일로 저장]      │
│ 불러오기: [파일에서] [붙여 넣어서]        │
└──────────────────────────────────────┘
```

- 공유하기: 아이폰 공유 창으로 백업 **파일**을 보낸다 (카카오톡 나와의 채팅 등). 공유를 못 하는 브라우저는 파일로 저장
- 텍스트로 복사: 백업을 글자로 복사. 복사가 막히면 글자를 보여 주고 직접 복사
- 불러오기: 형식·버전 검사 → 확인 창 → 지금 기록을 모두 바꾼다
- 파일 이름: `routine-backup-YYYY-MM-DD.json`
- 마지막 내보내기 후 14일이 지나면 백업 탭에 빨간 점 (아이폰 Safari는 오래 안 쓰면 사이트 데이터를 지울 수 있음)

## 3. 계산 규칙

| 규칙 | 내용 |
|---|---|
| 하루 합계 | 그날 해당하는 항목 중 합계에 들어가는 것의 달성 수 / 그 항목 수. 그날 요일이 아닌 항목(`-`)은 뺀다 |
| 체크 달성 | O 또는 △ |
| 시간 입력 달성 | 목표 이전(또는 이후). 목표가 없으면 기록만 하고 합계에서 뺀다 |
| 밤 시간 해석 | 0~6시 → 다음 날 새벽, 6~18시 → +12시간(11:00 → 23:00), 18~24시 → 그대로 |
| 취침 날짜 | 그날 밤 누운 시간을 그날에 기록 (11/16 밤 0:30에 잠 → 11/16 취침 00:30, 미달성) |
| 켜기/끄기 달성 | 켜면 달성: 켰을 때 +1 · 끄면 달성: 껐을 때 +1 · 안 넣음: 횟수만 |
| 입력 없는 날 | 아무것도 입력하지 않은 날은 0 ('끄면 달성' 항목도 점수 없음) |
| 이틀째 0 경고 | 지난 날: 그날과 전날이 모두 0. 오늘: 어제와 그제가 모두 0이고 오늘도 아직 0. 처음 쓴 날 이전은 계산하지 않음 |
| 이어간 주 | 이틀 연속 0이 없었던 주가 몇 주 연속인지 (진행 중인 이번 주 포함). 12주가 끝나도 0으로 돌아가지 않음 |
| 그날 할 일 | 오늘은 지금 설정으로 계산 (항목을 추가하면 바로 나옴). 끝난 날은 마감할 때 채운 필드가 곧 목록 → 설정을 바꿔도 지난 날은 그대로 |

입력 형식: `HH:MM`, `H:MM`, `HHMM`(예: 2330)을 받아 `HH:MM`으로 저장한다.

## 4. 데이터 모델

```js
// 설정 (한 개, 키 "main")
settings = {
  version: 1,
  startDate: "2026-11-16",      // 처음 쓰기 시작한 날
  lastExportAt: null,           // 마지막 백업 날짜
  items: [                      // 배열 순서 = 화면 순서
    { id, type: "check",  name, slots: [{ days: [1,3,5], time: "19:00", min: 30, note: "걷기" }] },
    { id, type: "time",   name, days: [0..6], goal: "07:30", dir: "before" | "after", night: false },
    { id, type: "toggle", name, days: [0..6], score: "none" | "on" | "off" },
    // 공통: archived: true 이면 삭제(숨김)
  ],
}
// days: 0=일 1=월 ... 6=토 (JS Date.getDay()와 같게)

// 하루 기록 (날짜마다 한 개, 키 = "YYYY-MM-DD"). 항목 id를 필드명으로 값만 저장
day = {
  date: "2026-11-17",
  marks:   { workout: "O", reading: null },   // 체크: "O" | "△" | "X" | null(입력 안 함)
  times:   { wake: "07:20", bed: null },      // 시간 입력: 입력한 시각 (밤 해석은 계산할 때)
  toggles: { latesnack: true, vitamin: false }, // 켜기/끄기
  note: "",
  closed: true,                               // 마감한 날 (끝난 날)
}
// 오늘: 입력한 값만 들어 있고, 화면의 할 일 목록은 지금 설정으로 계산
// 마감: 다음에 앱을 열 때 끝난 날(처음 쓴 날 ~ 어제)에 그날 할 일 중 없는 필드를 null/false로 채움
// 끝난 날: 필드가 있으면 그날 할 일, 없으면 그날 할 일이 아님('-')
// 값을 지울 때는 필드를 없애지 않고 null/false로 둔다

// 백업 파일 (버전 1의 scheduled 목록 형식도 불러올 수 있고, 앱을 열 때 새 형식으로 바뀜)
backup = { app: "routine", version: 2, exportedAt, settings, days: [day, ...] }
```

## 5. 코드 구조

```
src/
  main.jsx, App.jsx        탭 이동, 상태와 저장 연결
  ui.jsx                   아래에서 올라오는 창, 확인 창, 알림
  components/TimeField.jsx 시간 입력칸 (칸을 벗어날 때 HH:MM으로 저장)
  screens/                 Today · Week · Settings · Backup
  lib/
    rules.js               계산 규칙 (화면과 분리, rules.test.js)
    storage.js             저장소. IndexedDB는 이 파일에서만 (storage.test.js)
    defaults.js            처음 실행할 때의 예시 루틴, 새 항목 기본값
    dates.js               날짜·시간 계산
public/
  manifest.webmanifest, icons/ (180·192·512)
```

### storage.js 약속 (클라우드 DB로 바꿀 때 이 파일만 바꿈)
```js
getSettings(): Promise<settings | null>
saveSettings(settings): Promise<void>
getDay(date): Promise<day | null>
saveDay(day): Promise<void>
getAllDays(): Promise<day[]>
getDays(fromDate, toDate): Promise<day[]>
exportAll(): Promise<backup>
importAll(backup): Promise<void>   // 형식 검사 후 전체 교체
```

### 홈 화면 설치 (아이폰 Safari)
- `manifest.webmanifest`: start_url·scope `/routine/`, display `standalone`
- `index.html`: `apple-touch-icon`, `apple-mobile-web-app-capable`
- Vite `base: "/routine/"` (GitHub Pages 주소에 맞춤)

## 6. 남은 확인

- 아이폰 Safari에서 공유하기(파일 공유)와 홈 화면 설치 동작
- 오래 안 썼을 때 기록이 지워지는지 (저장 공간 유지 요청 `navigator.storage.persist()`를 넣어 둠)
